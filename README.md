# 🍲 মিল ট্র্যাকার (Meal Tracker)
> **ব্যাচেলর মেস ও ফ্ল্যাটের স্মার্ট মিল, বাজার খরচ ও ফান্ডের স্বয়ংক্রিয় হিসাবপত্র**  
> লাইভ ড্যাশবোর্ড • ফায়ারবেস ক্লাউড সিঙ্ক • এডমিন কন্ট্রোল • অ্যান্ড্রয়েড APK ও PWA রেডি

---

## 📌 ওভারভিউ (Overview)
**মিল ট্র্যাকার (Meal Tracker)** হলো ব্যাচেলর মেস ও ফ্ল্যাটের সদস্যদের জন্য তৈরি একটি সম্পূর্ণ ডিজিটাল ও স্বয়ংক্রিয় হিসাবরক্ষণ সিস্টেম। এটি গুগল স্প্রেডশিটের গতানুগতিক হিসাবকে একটি আধুনিক, রেসপনসিভ ও মিনিমাল ওয়েব ও মোবাইল অ্যাপ্লিকেশনে রূপান্তর করেছে।

---

## 🚀 প্রধান ফিচারসমূহ (Key Features)

### 💰 ১. মেস ফান্ড ও বাজার মডেল (Common Fund Model)
- **মোট ফান্ড জমা (Total Deposit):** সকল সদস্যের জমা করা টাকা একত্রিত হয়ে মেসের মূল ফান্ড তৈরি করে।
- **ফান্ড থেকে বাজার খরচ কর্তন:** প্রতিদিনের বাজার খরচ কোনো ব্যক্তির ব্যক্তিগত খরচ হিসেবে নয়, বরং মেসের মূল ফান্ড থেকে সরাসরি বিয়োগ হয়।
- **বাজারকারী শুধু ট্র্যাকিংয়ের জন্য:** বাজারে ক্রেতার নাম রাখা হয় শুধু তথ্য হিসেবে (কে বাজার করেছে তা দেখার জন্য)।
- **অবশিষ্ট ক্যাশ ফান্ড:** `মোট জমা - মোট বাজার খরচ` তাৎক্ষণিকভাবে লাইভ হিসাব হয়।

### 📊 ২. লাইভ মিল রেট ও মেম্বার ব্যালেন্স
- **স্বয়ংক্রিয় মিল রেট:** `মোট বাজার খরচ ÷ মোট মিল সংখ্যা`।
- **সদস্য ব্যালেন্স:** `[সদস্যের ফান্ডে জমা] - [তার মোট মিল × মিল রেট]`
  - ব্যালেন্স পজিটিভ হলে: মেস ফান্ড থেকে টাকা **ফেরত পাবেন (+)**।
  - ব্যালেন্স নেগেটিভ হলে: ফান্ডে টাকা **পরিশোধ করবেন (-)**।

### 🔐 ৩. এডমিন মোড ও নিরাপত্তা (Admin Controls)
- **সাধারণ ভিউয়ার মোড:** মেম্বাররা শুধু তাদের মিল, বাজার ও ব্যালেন্স দেখতে পারবেন। ভুলবশত কোনো ডেটা বদলাতে পারবেন না।
- **এডমিন লগইন (ডিফল্ট পিন: `1234`):**
  - দৈনিক মিল খাতায় `+` / `-` বাটন সক্রিয় হয়।
  - নতুন বাজার এন্ট্রি ও ডিলিট করা যায়।
  - বাসা ভাড়া ও ইউটিলিটি বিল যোগ করা যায়।
  - নতুন মেম্বার যুক্ত বা মেম্বার ডিলিট করা যায়।

### ☁️ ৪. ফায়ারবেস রিয়েল-টাইম ক্লাউড সিঙ্ক (Firebase Firestore)
- গুগলের **Firebase Firestore** ডেটাবেজের সাথে সরাসরি কানেক্টেড।
- একজন সদস্য তার ফোন থেকে বাজার বা মিল পরিবর্তন করলে বাকি সবার ফোনে **১ সেকেন্ডের মধ্যে লাইভ অটো-আপডেট** হয়ে যায়।

### 🏠 ৫. বাসা ভাড়া ও ইউটিলিটি বিল ম্যানেজমেন্ট
- বাসা ভাড়া, ওয়াইফাই, বুয়া বিল, বিদ্যুৎ ও গ্যাস বিল এন্ট্রি।
- মাথাপিছু ভাগ ও পরিশোধের অবস্থা (পরিশোধিত / বকেয়া) টগল করার সুবিধা।

### 🤝 ৬. স্মার্ট ঋণ নিষ্পত্তি (Zero Confusion Settlement)
- কে কাকে কত টাকা সরাসরি দেবে তার নিখুঁত হিসাব নির্দেশিকা।
- ওয়ান-ক্লিক **হোয়াটসঅ্যাপ গ্রুপ রিপোর্ট** জেনারেটর।

### 📱 ৭. মোবাইল অ্যাপ ও APK সাপোর্ট
- **PWA (Progressive Web App):** প্লে-স্টোর ছাড়াই সরাসরি ব্রাউজার থেকে ফোনে "Install App" করা যায়।
- **Capacitor Android:** প্লে-স্টোর ছাড়া সরাসরি অফলাইন ইনস্টলযোগ্য `.apk` বিল্ডের জন্য প্রস্তুত নেটিভ অ্যান্ড্রয়েড প্রজেক্ট।

## 📂 ফাইল ও ফোল্ডার স্ট্রাকচার (Directory Structure)

```text
mess-manager/
├── index.html            # মূল অ্যাপ ইন্টারফেস (Semantic HTML5)
├── style.css             # মিনিমাল ডিজাইন সিস্টেম (Light / Dark থিম)
├── app.js                # কোর ক্যালকুলেশন ইঞ্জিন, ফিল্টারিং ও স্টেট ম্যানেজমেন্ট
├── firebase.js           # ফায়ারবেস ক্লাউড রিয়েল-টাইম সিঙ্ক মডিউল
├── server.js             # লোকাল লাইটওয়েট নোড সার্ভার (Port 3000)
├── manifest.json         # মোবাইল অ্যাপ PWA ইনস্টলেশন কনফিগ
├── sw.js                 # অফলাইন ক্যাশিং সার্ভিস ওয়ার্কার
├── package.json          # নোড ও ক্যাপাসিটর ডিপেন্ডেন্সি
├── capacitor.config.json # অ্যান্ড্রয়েড অ্যাপ কনফিগারেশন
├── www/                  # ক্যাপাসিটর প্রজেক্টের বিল্ড এসেটস
└── android/              # ফুল নেটিভ অ্যান্ড্রয়েড প্রজেক্ট (Gradle)
```

## 💻 লোকাল মেশিনে কীভাবে রান করবেন (How to Run Locally)

### ১. ডিপেন্ডেন্সি ইনস্টল (যদি প্রয়োজন হয়):
```bash
npm install
```

### ২. লোকাল সার্ভার চালু করুন:
```bash
node server.js
# অথবা
npm start
```
ব্রাউজারে যান: **[http://localhost:3000](http://localhost:3000)**

## 📲 অ্যান্ড্রয়েড APK তৈরির নিয়ম (Build Android APK)

### উপায় ১: WebIntoApp দিয়ে ১ ক্লিকে APK
1. অ্যাপটি [Vercel](https://vercel.com)-এ ফ্রি হোস্ট করে লিংক নিন।
2. [www.webintoapp.com](https://www.webintoapp.com)-এ লিংক দিয়ে **"Make APK"** চাপুন।
3. ডাউনলোড করা `.apk` ফাইলটি সরাসরি যেকোনো অ্যান্ড্রয়েড ফোনে ইনস্টল করুন।

### উপায় ২: গিটহাব অ্যাকশন্স (GitHub Actions Cloud Build)
প্রজেক্টে `.github/workflows/build-apk.yml` যুক্ত করা রয়েছে। গিটহাবে কোড পুশ করলেই **Actions** ট্যাব থেকে স্বয়ংক্রিয়ভাবে তৈরি হওয়া **`MealTracker-Debug-APK`** ডাউনলোড করে নিতে পারবেন।
